# Oil Shop Artwork

These raster assets were generated for Scripture Memo's visual-first Oil Shop.
They share the approved cream, charcoal, amber, gold, indigo, and restrained
violet palette. Product art contains no embedded labels so accessible HTML owns
all names, quantities, prices, and translation-ready copy.

| File | Use |
|---|---|
| `luna-shopkeeper-hero.png` | Responsive Oil Shop environment banner |
| `single-spark.png` | One-hint product, preview, and celebration |
| `traveler-pack.png` | Three-hint product, preview, and celebration |
| `lantern-pack.png` | Five-hint product, preview, and celebration |

The hero was generated from `luna-reward.png` as an identity reference. Product
images are square inventory scenes and should use `object-cover` without being
stretched.
